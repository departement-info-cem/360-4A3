# 🧾 Écrire en Typst

Typst est un langage de **mise en page** moderne et puissant.

Il permet de rédiger des documents scientifiques (rapports, mémoires, articles) avec une qualité professionnelle.

Sa syntaxe est **simple** et **intuitive**, inspirée de Markdown et LaTeX.

:::tip-nt
### 📝 Gabarit
Vous pouvez [télécharger ce gabarit Typst](/ressources/gabarits/gabarit_rapport_typst.zip) pour démarrer rapidement votre premier document Typst.
:::

## ⚙️ Procédure simple et rapide

:::info-nt
### 1️⃣ Ouvrir / créer un projet
- Lancez **Visual Studio Code**
- `Fichier → Ouvrir le dossier`
- Sélectionnez le dossier de votre projet
- Ouvrez ou créez un fichier avec l’extension `.typ`
:::

:::info-nt
### 2️⃣ Installer l’extension Typst
- Ouvrez l’onglet **Extensions** à gauche : <img src="/360-4A3/img/extensions.png"/>
- Recherchez : **Tinymist Typst**
- Auteur : *myriad-dreamin*
- Cliquez sur **Installer**
:::

:::info-nt
### 3️⃣ Configurer l’extension Typst
Pour que le PDF soit (re)généré automatiquement lorsque vous tapez, vous devez configurer l’option `Tynymist Export PDF` :
- `Fichier → Préférences → Paramètres`
- Recherchez : `Tynymist Export PDF`
- Sélectionnez : `onType` : <img src="/360-4A3/img/pdf3.png"/>
:::

::::info-nt
### 4️⃣ Écrire et prévisualiser le PDF
- Ouvrez votre fichier `.typ`
- En haut à droite, cliquez sur l’icône de la loupe avec un document : <img src="/360-4A3/img/pdf2.png"/>
- Cela ouvre un panneau latéral avec l’aperçu du PDF.
- ✨ L'aperçu se met à jour **automatiquement** lorsque vous modifiez le code Typst
- ✨ Le vrai PDF se met aussi à jour automatiquement, **si vous avez configuré l’option `onType`**
- **Mais :**

:::danger ATTENTION
### ⚠️ Sauvegarder le fichier `.typ`
- VS code ne sauvegarde pas automatiquement votre fichier `.typ`, même si le PDF est mis à jour
- Pensez à sauvegarder régulièrement avec `Ctrl + S`
- 👉 Si vous fermez VS Code sans sauvegarder, vous perdrez vos modifications
- 👉 Si vous faites un commit-push avant de sauvegarder, vous pousserez la dernière version sauvegardée
:::
::::
