# 📄 Écrire en LaTeX

LaTeX est un langage de **composition de documents scientifiques** largement utilisé
dans les domaines des **mathématiques**, de l’**informatique** et des **sciences**.

Il permet de produire des rapports **structurés**, **lisibles** et **conformes aux normes académiques**.

Sa syntaxe est plus exigeante que Typst, mais elle est **très robuste** et **standardisée**.

:::info-nt
LaTeX est particulièrement adapté si :
- votre projet contient beaucoup de **mathématiques**
- vous souhaitez un contrôle fin de la typographie
:::

::::warning
LaTeX nécessite qu'une distribution LaTeX comme **TeX Live** soit installée sur votre ordinateur.

:::danger-nt
Malheureusement, aucune distribution LaTeX n’est présentement disponible sur les ordinateurs du cégep.
:::

Si vous tenez à utiliser LaTeX, vous devrez installer **TeX Live** sur votre ordinateur personnel.
::::
