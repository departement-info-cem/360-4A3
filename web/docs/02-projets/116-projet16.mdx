## Simulation d’un phénomène de diffusion par marche aléatoire

:::info-nt
### 🧭 Phénomène étudié
À l’échelle microscopique, le mouvement de particules peut comporter une importante composante aléatoire.

Même lorsqu’il est impossible de prédire précisément la trajectoire d’une particule individuelle, le comportement d’un grand nombre de particules peut présenter des **propriétés statistiques régulières**.

Une marche aléatoire constitue un modèle simple permettant d’explorer ce type de phénomène.
:::

:::tip-nt
### 🔬 Intérêt scientifique
Ce projet illustre comment le **hasard à l’échelle individuelle** peut produire des comportements prévisibles à l’échelle d’une population.

Il permet d’explorer :
- les probabilités et les simulations aléatoires
- la répétition d’expériences numériques
- l’analyse statistique des résultats
- la relation entre un modèle microscopique et un phénomène macroscopique

👉 Une seule simulation signifie peu de choses : l’intérêt scientifique vient notamment de la répétition et de l’analyse statistique.
:::

:::note-nt
### 📂 Pistes de données ou d’expérience
- Simulation de particules effectuant une marche aléatoire
- Simulation en une ou deux dimensions
- Paramètres contrôlables :
  - nombre de particules
  - nombre de déplacements
  - longueur des déplacements
  - probabilités associées aux directions
- Données entièrement générées par simulation
:::

:::info-nt
### ❓ Directions possibles à explorer
- Étudier comment la distance moyenne à l’origine évolue avec le nombre de déplacements
- Comparer une marche en une et deux dimensions
- Étudier l’effet du nombre de particules sur la stabilité des résultats
- Introduire un biais dans les probabilités de déplacement
- Comparer les résultats simulés à une relation théorique
- Analyser la distribution finale des positions
:::
